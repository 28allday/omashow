# Security

OmaShow opens decks that other people send you: OmaShow, PowerPoint and
Keynote files, and the pictures, SVGs and films inside them. A file that can
make OmaShow read something it shouldn't, run something, crash or hang is a
security problem, and reports are welcome.

## Reporting a problem

Please report it privately, not in a public issue:

1. Open the **Security** tab of this repository.
2. Choose **Report a vulnerability**, and describe what happens and how to
   make it happen. A small file that shows it is the most useful thing you can
   send.

You'll get a reply as soon as it has been looked at. Once a fix is released,
the report can be made public, with credit to you if you'd like it.

## What is supported

Fixes go into the latest release. Update OmaShow before reporting, in case it
is already fixed.
